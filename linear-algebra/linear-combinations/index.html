    What you're looking at

    w = c₁v₁ + c₂v₂ + … + cₙvₙ

    Each coefficient stretches its vector — negative values flip it around the origin — and the results are added nose to tail. The dashed path on the grid is that addition happening one term at a time: start at the origin, walk along c₁v₁, then from wherever you land walk along c₂v₂, and so on. The dark arrow from the origin to the final stop is w.

    The order you walk in doesn't matter — vector addition commutes, so rearranging the terms changes the dashed path but never the endpoint. Two vectors pointing in genuinely different directions can reach every point in the plane between them; two that lie on a common line can only ever reach that line, no matter what coefficients you choose. That distinction is linear independence, and you can feel it by dragging one vector until it lines up with another and watching the reachable set collapse.
