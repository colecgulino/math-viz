Column Spaces

The equation Ax = b is usually taught as a system to be solved. Read it the other way round and it says something simpler: it asks whether b is one of the vectors you can build out of the columns of A. The set of all the ones you can is a subspace, and it has a name.

Ax is a linear combination of the columns

Write A out by its columns rather than its rows. A 3×2 matrix is two vectors in ℝ³ standing side by side, and x is a pair of scalars. Multiplying them out gives:

A = [ a₁  a₂ ]     two columns, each a vector in ℝ³

Ax = x₁a₁ + x₂a₂

That is the same move as linear transformations, where the columns were the landing spots of î and ĵ and the coordinates told you how much of each to take. Here the coordinates live in x, but the arithmetic is identical: the entries of x are the coefficients, the columns of A are the ingredients, and b is what you get when you mix them.

a₁ = (2, 1, −1)  a₂ = (1, 2, −2)  x = (2, −1)

b = 2(2, 1, −1) + (−1)(1, 2, −2)
  = (4, 2, −2) + (−1, −2, 2)
  = (3, 0, 0)

So solving Ax = b means hunting for coefficients that mix the columns into b. If no such coefficients exist, the system has no solution — not because the arithmetic went wrong, but because b was never reachable in the first place.

The column space

Sweep x over every possible pair of scalars and collect all the b you get. That collection is the column space of A, written Col(A).

Col(A) = { Ax : x ∈ ℝⁿ } = span{ a₁, a₂, … , aₙ }

Written that way it is nothing new. It is the span of the columns, and a span is always a subspace: it contains 0 (take every coefficient zero), the sum of two combinations is a combination, and a scaled combination is a combination. All three subspace conditions, satisfied for free.

Which turns a question about solving equations into a question about geometry. Ax = b has a solution exactly when b lies inside Col(A), and no amount of algebra will find one when it does not.

Why ℝ³ needs three columns

However you fill in a 3×2 matrix, the board never tints all of space. The reason is a counting argument rather than a geometric accident: the span of n vectors has dimension at most n. Two columns give you at most a plane — less if they happen to line up, and nothing at all if they are both zero.

dim Col(A)  =  rank(A)  ≤  number of columns

So a 3×2 matrix always leaves most of ℝ³ unreachable. Pick a b off that plane and Ax = b has no solution, for any x at all. To reach every point of ℝ³ you need a 3×3 matrix, and not just any one: its three columns have to be linearly independent. If they are, the rank is 3, the column space is all of ℝ³, and Ax = b is solvable for every b. If they are not — if one column is a combination of the other two — the rank drops back to 2 and the column space collapses to a plane again, which is exactly the zero determinant case seen from the other side.

The identity is the easy case: its columns are the standard basis, so they are independent and Col(I) is the whole space. Ax = b becomes x = b. The zero matrix is the opposite extreme: every column is 0, every combination of them is 0, and the column space is the zero subspace.

A diagonal matrix scales each axis independently, so its columns are the standard basis vectors stretched by the diagonal entries. As long as none of them is zero the directions are untouched and the column space is everything. Put a zero in the ith diagonal slot and that whole column vanishes; the column space drops to the span of the remaining axes — a coordinate plane, or a line.

Triangular matrices behave the same way for the same underlying reason: their determinant is the product of the diagonal entries, so they are invertible precisely when no diagonal entry is zero, and invertible is the same as full column space. A zero on the diagonal costs you a dimension.

The matrices themselves form a space

Everything above treats a matrix as a machine acting on vectors. There is a second, quite different reading: treat the matrix as itself a vector. You can add two matrices, you can scale one by a number, and those operations satisfy all eight axioms. So the set of all 3×3 matrices is a vector space, of dimension 9 — one dimension per entry.

That immediately raises the subspace question. Do the diagonal matrices form a subspace of it? Run the three-part test:

the zero matrix is diagonal   ✓ contains 0
diagonal + diagonal = diagonal   ✓ closed under addition
c · diagonal = diagonal   ✓ closed under scaling

All three hold, so the diagonal matrices are a genuine subspace — of dimension 3 inside the 9, one per diagonal slot. Adding two diagonal matrices can never wake up an off-diagonal entry, because zero plus zero is zero, and scaling cannot either. The same argument works for the upper triangular matrices (dimension 6) and for the symmetric matrices. Notice these are statements about closure, not about what the matrices do: the diagonal matrices are closed under addition even though they are not closed under, say, inversion of a singular one.

A set that fails

Now take the set of matrices whose entries are all strictly negative. It is worth working through carefully, because it fails in an instructive way — one of the three conditions actually holds:

the zero matrix has entries 0, not negative   ✗ no zero
negative + negative = negative   ✓ closed under addition
(−1) · negative = positive   ✗ leaves the set

Adding two all-negative matrices really does give an all-negative matrix, so closure under addition is satisfied. It is not enough. Scaling by −1 flips every entry positive and lands outside the set, and scaling by 0 produces the zero matrix, which is also outside. The set is not a subspace, and the same reasoning rules out the vectors in ℝ² with both entries positive, the unit circle, and any region that does not stretch away from the origin in both directions forever.

This is why closure under scaling is the condition that does most of the work. It forces a subspace to be unbounded, to be symmetric through the origin, and to contain 0 — all from one requirement.

Reading the board

The two solid arrows are the columns of A, drawn in ℝ³. The tinted sheet is Col(A) — every vector you can build from them. The dashed pair shows the recipe being carried out: walk x₁ along the first column, then x₂ along the second from wherever you land, and the dark arrow to the finish is b.

The thing to notice is what never happens. Move both sliders through their whole range and b stays welded to the sheet. There is no setting of x that lifts it off, because every reachable point is a combination of the columns and the sheet is precisely the set of those combinations. Any b you can point to off the sheet corresponds to a system with no solution.

Try the Line preset, where the second column is a multiple of the first. The sheet collapses, the rank drops to 1, and two independent knobs now steer along a single direction — different pairs of coefficients produce the same b. That is the column-space view of a matrix losing rank, and it is the same collapse a zero determinant causes and the same one that turns a span from a plane into a line.
